# Maison Veritas: Decarbonisation Business Case and Carbon Cost Exposure Model

An Excel decarbonisation business case for an illustrative European mid-sized manufacturer. It appraises six decarbonisation measures, ranks them on a marginal abatement cost curve (MACC), and quantifies the company's carbon cost exposure for 2026–2035, with and without acting, under low, central and high carbon price scenarios.

"Maison Veritas" is a fictitious company. The data is real. The baseline is a representative Belgian chemicals manufacturer (NACE C20) built from official Eurostat sector statistics. Every input is either cited to an official source or labelled as an analyst assumption with its rationale.

**Download the workbook:** see the [v1.0 release](../../releases). The file is `maison_veritas.xlsx`, with live formulas, native charts and no macros.

## What the model does

| Area | Content |
|---|---|
| Baseline | Energy use by carrier; Scope 1, Scope 2 (location-based and market-based, reported side by side and never summed) and Scope 3 |
| Measures | Rooftop solar, heat pump, LED lighting, fleet electrification, renewable electricity contract, variable-speed drives |
| Appraisal | Yearly cash flows, NPV, IRR, payback, abatement cost (€/tCO₂e) and break-even carbon price for each measure |
| MACC | Variable-width bar chart and a ranked "what to do first" table, switchable between location-based and market-based |
| Carbon exposure | 2026–2035 carbon cost through EU ETS2 on fuels and EU ETS pass-through in electricity prices, plus an internal carbon price shown as a separate lens. NGFS-based scenarios; direct EU ETS coverage as a toggle |
| Sensitivity | NPV grids for discount rate, energy prices and carbon price (plain formulas, no Data Tables), a tornado chart and MACC rank stability |
| Disclosure | Outputs mapped to IFRS S2 and ESRS E1, each rated Direct / Supports / Not covered. References that could not be read in the official text are flagged as unverified |
| Checks | Reconciliation checks rolled up into a master OK / ERROR flag shown on the Cover and the Dashboard |

Three dropdowns change the whole workbook: emissions basis, carbon price scenario, and direct EU ETS coverage.

## Workbook structure

16 sheets: Cover · ReadMe · Dashboard · Inputs · Sources · Baseline · Rates · Carbon · Measures · MACC · Exposure · Sensitivity · Disclosure · Checks · Notes · Lists.

The colour key separates inputs, formulas and links. Each result traces back through live formulas to an input, and each input to an entry on the Sources sheet or a labelled assumption. Notes covers the method choices, limitations (including the standard MACC critiques) and the version log.

## Data sources

Eurostat (energy prices, energy balances, air emissions, business statistics), European Environment Agency, AIB European Residual Mixes, UK DESNZ conversion factors, JRC PVGIS, Danish Energy Agency technology catalogues, PBL SDE++, RVO, NGFS scenarios (via IIASA), EEX, ECB, Damodaran (NYU Stern), EUR-Lex and the European Commission. ## How it is built and verified

The workbook is generated by a deterministic, offline Python build (XlsxWriter). The same inputs always produce the same file.

- **Independent reference model:** `checkmodel/` re-implements the whole model in pure Python. Every formula's stored value comes from it, and the tests compare the two cell by cell.
- **Excel recalculation:** `tools/excel_check.py` opens a throwaway copy in Excel desktop and recalculates every formula in all 12 selector combinations. The v1.0 result: 12,291 formulas per state, 0 mismatches, 0 error values, master flag OK.
- **Tests:** 722 unit and integration tests, covering formula lint, provenance, check behaviour (each check must be able to fail, and must not fail on valid inputs), and walkthrough figures that must match the workbook.
- **Security:** a default-deny scan of the file package (no macros or external links), allowlisted source domains, and hash-pinned dependencies. See [`docs/SECURITY.md`](docs/SECURITY.md).
- **Compatibility:** verified in Excel desktop. Not verified in Excel for the web.

The verification record is in [`docs/EXCEL_CHECKS.md`](docs/EXCEL_CHECKS.md).

## Run it yourself

Requires Python 3.9+. Dependencies are hash-pinned. See [`docs/SECURITY.md`](docs/SECURITY.md) for the full install procedure.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --require-hashes --only-binary :all: --no-deps -r requirements.txt

.venv/bin/python build.py                              # -> dist/maison_veritas.xlsx
.venv/bin/python -m unittest discover -s tests -t .    # full test suite (about 15 minutes)
```

`build.py --dataset fixtures` builds a synthetic test workbook, marked with a SYNTHETIC banner.

## Limitations

This is an illustrative model, not advice for a real company. It is pre-tax and ex-VAT, treats measures as independent of each other, and uses NGFS shadow prices converted to euros. The ETS2 start date and some regulatory references carry the uncertainty noted in the workbook. The Notes sheet lists all limitations.
